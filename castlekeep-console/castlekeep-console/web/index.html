Things to try

A normal trade

Lock 1 BTC, mine a block, sell 0.6 BTC, then settle and mine a block. Your unsold BTC returns with no waiting.

The exchange disappears

Lock and confirm, set the exchange to offline, request an exit, mine a block. Try to claim (refused), mine 144, then claim.

Try to undo a sale

Sell at $65,000, raise the price to $70,000, request an exit and mine a block. The exchange publishes the sale you already signed.

A malicious exchange

Sell 0.5, buy 0.5 back, set the exchange to malicious, request an exit and mine a block. This shows the gap version 2 closes.

Attempted theft

With a vault open, press "Have the exchange try to steal". The node refuses: your signature is missing.
