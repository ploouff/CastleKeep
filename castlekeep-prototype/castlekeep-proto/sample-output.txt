  • BTC rises to $70,000. User refuses to settle and broadcasts the exit request instead.
  ✔ Exit request confirmed; the 144-block response window starts (accepted)
  • Exchange watchtower sees the exit request and publishes the latest state the user signed.
  ✔ Exchange's settlement accepted inside the window (accepted)
  ✔ Buyer's 0.6 BTC goes to the exchange: 0.59999400 BTC
  ✔ User keeps only the unsold 0.4 BTC: 0.39998600 BTC
  ✔ User's attempt to claim the whole vault after 144 blocks is REJECTED (node: the exit output was already spent by the exchange's settlement)
